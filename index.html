Training Dashboard

Connect intervals.icu

This page reads your training from intervals.icu and turns it into a plain-language summary, four charts and a report you can paste into Claude for coaching.

  1. Sign in to intervals.icu and open Settings.
  2. Scroll to Developer Settings. Copy your Athlete ID (it looks like i12345) and your API Key (click View, or generate one if there is none).
  3. Paste both below.

Privacy. Your key is stored only in this browser and is sent only to intervals.icu. There is no server behind this page; nothing about you is stored anywhere else. Clear it any time from Settings.

Charts depend on your intervals.icu settings: heart-rate zones for each sport, and threshold pace for running.
